Claude Context Manager (cctx)

Go, Cobra, Claude Code, Jira (Atlassian MCP), Git
A CLI I built and use daily on my own development work to manage per-ticket context files for AI-assisted development.

  • Workflow: Auto-detects ticket IDs from git branches and archives a ticket with its related docs in a single command.
  • Design: Symlink-based workspace and a JSON config (atomic writes) that links one ticket to multiple repositories. verify --fix, cleanup and --dry-run repair broken links and clear stale data safely.
  • AI Integration: Works with Claude Code and the Atlassian (Jira) MCP server to load ticket requirements and log each session automatically, so a ticket never has to be re-explained.
  • Quality: Unit and integration tests for the ticket, link, reset and archive flows, a Makefile build pipeline, embedded templates (go:embed) and bash/zsh/fish completions.
